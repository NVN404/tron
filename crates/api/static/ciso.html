Security Architecture & Attack Resistance Matrix

✓ Cross-Tenant IDOR Proof

Path parameters must match the authenticated token tenant identity. Unmatched probe attempts return 404 Not Found.

✓ Connection Pool State Isolation

Tenant context is established strictly using set_config(..., is_local=true), purging context immediately upon commit.

✓ Kernel-Level RLS Enforcement

Role api_ro has NOBYPASSRLS and is non-superuser. Policy bypass is blocked by the database engine.

✓ SQL Injection Immunity

All analytical aggregation queries execute through strictly parameterized statements with typed timestamp validation.

✓ Anti-Delta Drift Immunity

Aggregates are authoritatively recomputed in snapshot transactions. Blind incremental delta counters are strictly eliminated.

✓ Zero-Cache Proxy Protection

Mandatory injection of Cache-Control: no-store headers guarantees CDNs never cache tenant metrics.
